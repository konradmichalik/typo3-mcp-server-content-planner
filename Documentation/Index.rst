=================================
TYPO3 MCP Server Content Planner Bridge
=================================

:Extension key:
   typo3_mcp_server_content_planner

:Package name:
   konradmichalik/typo3-mcp-server-content-planner

:License:
   GPL-2.0-or-later

Bridges `typo3-mcp-server <https://github.com/hauptsacheNet/typo3-mcp-server>`__ and
`xima-typo3-content-planner <https://github.com/xima-media/xima-typo3-content-planner>`__,
exposing Content Planner's status, assignee and comment workflow as MCP tools for AI
assistants.
